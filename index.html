🔌 Windows & Mac USB Setup

🪟 Windows (10 / 11) — Plug & Play:

1. Plug your USB-to-TTL adapter into any USB port. Windows automatically detects it as COM3, COM4, etc.

2. Open in Google Chrome or Microsoft Edge.

3. Click Printer Settings → Connect Printer, pick your COM port from the list, and you're ready to print!

🍎 Mac Setup:

If your USB adapter isn't listed in Chrome, install the CH340 driver via terminal:

brew install --cask wch-ch34x-usb-serial-driver

Go to System Settings > Privacy & Security, click Allow, and restart your Mac.

⚡ Hardware Checklist:

• Wiring: Adapter TX → Printer RX, Adapter RX → Printer TX, GND → GND

• Power: 5V 3A (or 9V/12V 2A+) external adapter connected to printer power pins
